# Smart Expense Tracker API

A simple REST API for tracking personal expenses. Built with **Python + FastAPI**.
Data is stored **in memory** (a Python list) - it resets whenever the server restarts.

## What it does

- `POST /expenses` - add a new expense (title, amount, category, date). Server auto-generates the `id`.
- `GET /expenses` - view all expenses. Supports `?category=Food` to filter.
- `GET /expenses/total` - overall total + breakdown by category. Supports `?category=Food` for a single category's total.
- `DELETE /expenses/{id}` - delete an expense by id.

Interactive API docs (Swagger UI) are auto-generated by FastAPI at `/docs` once the server is running.

## Requirements

- Python 3.10+

## Install

```bash
python -m venv venv
source venv/bin/activate      # on Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Run the server

```bash
uvicorn src.main:app --reload
```

The API will be available at `http://127.0.0.1:8000`
Interactive docs at `http://127.0.0.1:8000/docs`

## Run the tests

```bash
pytest
```

## Example usage

```bash
# Add an expense
curl -X POST http://127.0.0.1:8000/expenses \
  -H "Content-Type: application/json" \
  -d '{"title": "Coffee", "amount": 4.5, "category": "beverage", "date": "2026-07-31"}'

# View all expenses
curl http://127.0.0.1:8000/expenses

# Filter by category
curl "http://127.0.0.1:8000/expenses?category=Food"

# Get totals
curl http://127.0.0.1:8000/expenses/total

# Delete an expense (replace 1 with a real id)
curl -X DELETE http://127.0.0.1:8000/expenses/1
```

## Design notes

- IDs are auto-generated by the server (incrementing integer) rather than supplied by the client, to avoid duplicate/conflicting IDs.
- Category matching is case-insensitive (`Food` and `food` are treated the same) so filtering is more forgiving.
- Data is in-memory only; restarting the server clears all expenses. This was a deliberate scope choice per the assignment (no database required).
